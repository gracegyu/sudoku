Description 
Welcome to Sudoku 9. 
You can enjoy new games every time with "Sudoku9" that provides infinite number of puzzles all your life. 

Sudoku is the most popular number puzzle. 
It is a logic-based, combinatorial number-placement puzzle. 

The objective is to fill a 9×9 grid with digits so that each column, each row, and each of the nine 3×3 sub-grids that compose the grid contains all of the digits from 1 to 9. The puzzle setter provides a partially completed grid, which typically has a unique solution. 

features 
- Provides infinite number of puzzles at all levels. 
Provides infinite number of puzzles and you can play it all your life. 

- You can choose game level among 5 different levels 

- Auto saving 
Always the state of games will be saved and then you can see the last screen when you restart the game. 

- Memo for candidate numbers 
You can enter candidate numbers 1-9 in a cell that you don't know the awnser immediately. It will help you to play the game. 

- Recording game score 
Score of the game is recorded and managed. 

- Resetting game 
If you screw up the game, you can initialize the game. 

- Unlimited undo 
You can go back previous status using undo function. 

- Supporting 7 languages (English, Korean, Japanese, French, German and 2 Chinese) 

- Hint function 
Hint function tells you the answer of a cell when you meet a difficult cell. 

- Display duplicate numbers 
When you enter a duplicate number, the number will be displayed with different color. It will help you to play games. 

- Full support for Retina display 
Provides clear screen with supporting Retina display 

- When you double tap the screen the mode will be changed to memory mode 

- Display with different color where you need to compare the numbers. 
The cells that you should compare the numbers will be painted with different color. It will help you to play games.
